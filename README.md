# Jetpack Compose Calculator

A simple Android calculator application developed using Kotlin and Jetpack Compose as part of an Android development assignment.

## Features

- Addition, subtraction, multiplication, and division
- Two numeric input fields
- Dynamic result display using Compose state
- Input validation for invalid numbers
- Division-by-zero handling with a Toast message
- User interface built with Jetpack Compose and Material 3

## Technologies

- Kotlin
- Android SDK
- Jetpack Compose
- Material 3
- Android Studio

## Project Purpose

This project was developed to practice building declarative Android user interfaces with Jetpack Compose, managing UI state, handling user input, and implementing basic arithmetic operations.
